# KAIZEN — Android discipline tracker

A minimal, offline-first Android app based on the seven habits in your Instagram reel.

## Included
- Seven habit cards with descriptions and a practical daily action
- Daily checkboxes and completion percentage
- Daily routine checklist
- 30-day habit history
- Streak counter (a streak day means all 7 habits were completed)
- Local storage using Android SharedPreferences

## Build an APK
This is the Android Studio project source, not a precompiled APK.

1. Install Android Studio on a computer.
2. Open this `KaizenDiscipline` folder.
3. Allow Gradle sync to finish (internet is needed for the first dependency download).
4. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Android Studio will show the APK location. Transfer it to your Android phone and install it.
6. If Android asks, allow installation from that source.

Minimum Android version: Android 6.0 (API 23).

## Notes
- Progress is stored locally on the device; uninstalling the app or clearing its data removes it.
- The app does not need an account or internet connection after installation.
- Habit ideas are motivational prompts, not medical or scientific guarantees.
